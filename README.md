# Tesla-social-media-analytics-excel
A complete Excel-based data analytics project analyzing Tesla’s social media performance across platforms. Includes data cleaning, engagement metrics, ROI, campaign effectiveness, and follower growth insights. Helps identify which content types and platforms drive the highest engagement and ROI.
Objectives

Clean and standardize raw social media data for analysis.

Measure engagement rates, impressions, and audience growth.

Evaluate campaign performance and ROI using Ad Spend data.

Identify best-performing hashtags, content types, and platforms.

Recommend data-backed strategies for future marketing campaigns.

📈 Key Insights

YouTube & X (Twitter) deliver the highest engagement efficiency.

Cybertruck Launch Campaign had the best ROI and strongest follower growth.

Videos outperform images and carousels in engagement metrics.

Top hashtags: #Cybertruck, #ModelY, #EVRevolution.

Recommended strategy: Focus on video-first content on YouTube + X, use image-driven storytelling on Instagram.

🧰 Tools Used

Microsoft Excel (Pivot Tables, AVERAGEIFS, SUMIFS, Conditional Formatting)

Data Visualization: Charts (Bar, Line, Scatter)

Statistical Methods: Moving averages, correlation analysis

Reporting: Campaign ROI and engagement uplift analysis
